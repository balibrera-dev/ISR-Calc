# ISR Calc

Calculadora de Impuesto sobre la Renta personal para El Salvador. Registra salarios, honorarios y gastos deducibles y obtén en tiempo real tu saldo anual (F11) según la tabla del Art. 37 LIR. Todo se guarda en tu navegador.

```bash
npm install
npm run dev      # desarrollo
npm test         # pruebas
npm run build    # producción -> dist/
npm run deploy   # Cloudflare Worker "isr-calc"
```

Documentación del proyecto: [`docs/knowledge/`](docs/knowledge/).
